# 要件（ドラフト）

## 目的
URL内のDB学習内容を、ジュニアエンジニアにも理解できるように「講義スライド風のSPA」として可視化する。

## 対象ユーザー
- DB内部に興味があるジュニアエンジニア
- MVCC/ロック/ログ周りがまだ曖昧な人

## 主要要件
- React（Vite）で構築する
- UIライブラリは MUI を使用
- フロントエンドのみ（API不要）
- データは JSON などの静的データで管理
- SPA でページ遷移がサクサク動く
- 講義スライドのようなUI
- ページ切り替え時にアニメーション（例：フェード/スライド）
- 用語解説はジュニアにも分かる言葉で
- 用語はスライド内から詳細参照できる（短文はツールチップ、詳解は右サイドパネル）
- コンポーネント責務を分離

## 非機能要件
- まずはローカルで動作（デプロイは後回し）
- 画像や動画は必須ではない（紙芝居風のテキスト＋図でOK）

## 想定ページ構成（例）
- イントロ（学習ゴール）
- Read View の生成タイミング
- 自己可視性（自分の更新が見える理由）
- MVCCの内部イメージ（Undo参照）
- RR と RC の比較
- 用語集（MVCC / Read View / Undo/Redo / WAL / ギャップロック など）

## 保留/確認事項
- 画面トーン（ライト/ダーク/講義スライド風の具体イメージ）
- 章立ての最終確定
