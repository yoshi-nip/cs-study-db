# 02. UI基盤（MUI）実装メモ

## 目的
- MUIのテーマを全体に適用し、共通デザインの土台を作る
- レイアウトの器（左/中央/右）を先に固定する

## 実装内容
- MUI導入（@mui/material + Emotion）
- `ThemeProvider` と `CssBaseline` を適用
- `AppLayout` / `AppHeader` / `ChapterSidebar` / `SlideCanvas` / `GlossaryPanel` を作成
- 3カラムレイアウト（lg以上で左右パネル表示）

## 使用したMUI要素（概要）
- `AppBar` / `Toolbar`: ヘッダの固定レイアウト用
- `Typography`: 文字階層を統一（見出し/本文）
- `Paper`: 右左パネルやスライドの「カード面」を表現
- `Stack`: 縦方向の余白管理を簡単にする
- `Box`: レイアウトの土台（gridやpadding）

## 学習の観点（どう考えて実装したか）
- **骨組み優先**: まず「配置」を決めてから内容を入れる
- **責務分離**: ヘッダ/左/中央/右で責務を分ける
- **拡張性**: 後からデータを流し込める形を意識

## 確認事項（セルフチェック）
- テーマが全体に適用されているか
- 余白や文字サイズが統一されているか
- 画面幅が狭いとき左右パネルが消えるか

## 意図
- 先に骨組みを作ることで、後からデータを流し込むだけにする
- コンポーネントを分割して責務を明確化
- レスポンシブは最小対応（小画面では左右パネルを非表示）

## つまずきポイント
- MUIが反映されない場合は `ThemeProvider` の位置を確認
- 既存のViteのCSSが残ると見た目が崩れるので `index.css` を簡素化
