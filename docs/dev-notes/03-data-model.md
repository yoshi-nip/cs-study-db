# 03. データ設計（JSON）実装メモ

## 目的
- スライド/用語のデータ構造を先に固め、UIをデータ駆動にする

## 実装内容
- `slides.json` と `glossary.json` を作成
- `SlideContent` / `GlossaryTerm` 型を定義
- `SlideCanvas` がJSONから表示するように更新

## 使用した要素（概要）
- JSON import（Viteの標準機能）
- `SlideContent` 型による型安全な参照

## 学習の観点（どう考えて実装したか）
- **データ→UIの順**: 先にデータ形を決めるとUIが迷わない
- **型で守る**: JSON構造と型を一致させて破綻を防ぐ
- **最小から**: まず1枚分の表示で動線を確認

## 確認事項（セルフチェック）
- JSONのキーと型が一致しているか
- 1枚目のスライドがUIに表示されるか
- 文字量がスライド内に収まるか

## 意図
- 将来はスライド切り替えを「ID指定」で行えるようにする
- glossaryは右パネル/ツールチップのデータソースになる

## つまずきポイント
- JSON importのパスがずれる → `src/data` 配下を基準に確認
- 型が一致しない → `SlideContent` の必須/任意を見直す
